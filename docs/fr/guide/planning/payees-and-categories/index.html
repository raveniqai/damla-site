Bénéficiaires et catégories

Comment Damla apprend où va l’argent et comment le modifier.

Sur cette page

  • Comment Damla apprend un bénéficiaire
  • Pendant un import : une question par bénéficiaire
  • Bon à savoir
  • À voir aussi

Un bénéficiaire est le magasin, l’entreprise ou la personne à qui l’argent est allé. Une catégorie est le compartiment dans lequel sa dépense ou son revenu est rangé, comme Courses ou Salaire. Cette page explique comment Damla classe chaque bénéficiaire la première fois, ce qu’il retient ensuite, et comment vous modifiez tout cela.

Quand l’utiliser

  • Une alerte bancaire ou un message collé a été classé dans la mauvaise catégorie, et vous voulez que les suivants soient corrects.
  • Vous voulez une catégorie à vous, ou un meilleur nom ou une meilleure icône pour l’une d’elles.
  • Vous avez importé un relevé et Damla demande « Qui sont ceux-ci ? » à propos de certaines lignes.
  • Vous voulez vérifier comment les écritures sont triées avant de faire confiance aux onglets Analyses.

Étape par étape

Touchez l’icône d’engrenage sur l’écran Aujourd’hui pour ouvrir Réglages, puis touchez Catégories.

  1. En haut, choisissez la liste voulue avec le sélecteur : Dépenses ou Revenus.
  2. Touchez Ajouter pour créer une nouvelle catégorie.
  3. Tapez le Nom. L’icône suit le nom pendant que vous tapez : beaucoup de types de dépenses (salle de sport, animaux, enfants, assurances, réparations et autres) reçoivent d’eux-mêmes une image correspondante.
  4. Pour choisir votre propre image, touchez-en une dans la grille intitulée Icône. Le texte sous le champ du nom indique alors « Votre propre icône. Choisissez-en une autre, ou touchez la même pour revenir à la suggestion. »
  5. Touchez Enregistrer. Touchez Annuler pour partir sans enregistrer.

Sur ce même écran :

  • Touchez une catégorie pour la renommer ou changer son icône dans la même feuille. C’est la même feuille aux deux endroits, intitulée Nouvelle catégorie ou Catégorie.
  • Balayez une catégorie et touchez Retirer pour la retirer.

Vous pouvez aussi créer une catégorie sur place : sous le sélecteur de Catégorie dans n’importe quel formulaire d’écriture, touchez Nouvelle catégorie…. Elle est sélectionnée tout de suite.

Comment Damla apprend un bénéficiaire

Quand vous enregistrez une transaction qui a un bénéficiaire dans une catégorie, Damla note la paire. La prochaine alerte ou le prochain message du même magasin ou de la même personne est classé dans cette catégorie tout seul, sans question.

Deux habitudes font que cela fonctionne :

  • Remplissez le champ du bénéficiaire. Le formulaire d’écriture l’intitule Payé à (facultatif) pour les dépenses et De la part de (facultatif) pour les revenus.
  • Si le type de paiement change, enregistrez-le dans la nouvelle catégorie. Si des transactions antérieures du même bénéficiaire se trouvent dans une autre, Damla demande avant d’y toucher : « Modifier les N autres bénéficiaires ? » avec Les passer en \<catégorie\> ou Seulement celle-ci. Il explique que dorénavant les nouveaux vont tout seuls dans la nouvelle catégorie.

Damla fait une exception pour le fourre-tout : quand vous enregistrez dans le formulaire et que la catégorie est Autre (ou Autres revenus pour les revenus), la paire n’est pas retenue. Une écriture laissée là ne lui apprend rien.

Pendant un import : une question par bénéficiaire

Quand vous importez un relevé (un fichier CSV, un PDF ou une capture d’écran), Damla regroupe les lignes par bénéficiaires inconnus, pour que vous répondiez une fois par bénéficiaire, pas une fois par ligne. La section est intitulée Qui sont ceux-ci ? (N restants), et on y répond avant que quoi que ce soit soit importé.

Chaque question montre le nom du bénéficiaire, combien de lignes il couvre, une ligne d’exemple, et un total de l’argent entré ou sorti. Touchez Choisir… dessus et choisissez parmi :

  • une de vos catégories existantes (la liste suit le sens de l’argent),
  • Utiliser la suggestion : …, le choix que Damla propose,
  • Une de mes cartes de crédit, quand les lignes sont des paiements à une carte,
  • Un autre de mes comptes, quand c’est de l’argent qui passe entre vos propres comptes,
  • Une propriété ou un bien que je paie,
  • Une personne (prêt/emprunt),
  • Ne pas importer ceux-ci, pour laisser les lignes de côté.

Les suggestions viennent de règles de formulation simples pour les lignes courantes : salaire, retrait d’espèces, frais bancaires, commission, EMI, prélèvement automatique, intérêts, etc. Là où l’iPhone prend en charge Apple Intelligence, le modèle sur l’appareil peut aussi proposer une catégorie. Il lit la formulation du bénéficiaire, quelques lignes d’exemple, combien de lignes le bénéficiaire couvre, et si l’argent est surtout entré ou sorti — jamais des soldes ni des montants. Le code vérifie ce que dit le modèle avant de l’utiliser. Un numéro de carte dans le texte du bénéficiaire, ou votre propre nom dans l’en-tête du relevé, est reconnu par le code, pas par le modèle.

Votre réponse compte comme la vérité pour ces lignes, et Damla garde les paires apprises pour la prochaine fois.

Bon à savoir

  • Quand deux motifs appris conviennent tous les deux, la correspondance la plus longue l’emporte, ainsi « XYZ Grocery » bat une simple règle « Grocery ».
  • Vous façonnez les catégories comme vous voulez : rien dans l’app ne dépend d’un nom particulier.
  • Retirer une catégorie la sort de vos sélecteurs. Les anciennes écritures gardent leur catégorie. La seule catégorie que l’app connaît par son nom, pour les frais de plan d’échelonnement, est recréée toute seule si elle manque.
  • L’étape du modèle est facultative et tourne sur votre appareil. Si l’appareil ne peut pas la faire tourner, les règles de formulation font quand même le travail, et tout attend que vous touchiez l’écran.
  • Damla donne des informations et des estimations. Décider à quelle catégorie appartient l’argent relève de votre propre comptabilité.
